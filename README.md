# A Brazileira — site

Página "Brevemente" de **A Brazileira · Boutique Hotel · Torres Vedras** e primeiro passo do design system do site.

- `src/` — fontes do site e do design system. `python3 src/build.py` gera `docs/`; depois `python3 tools/stamp_assets.py docs` (cache-busting).
- `docs/` — site público gerado (HTML/CSS/JS estático), publicado pelo GitHub Pages.
- `DESIGN.md` — design system: marca, logo, cores Dia/Noite, tipografia, movimento, componentes, regras anti-slop.
- `docs/design/` — styleguide (não indexado).
- `supabase/` — lista de espera (esquema e notas).
- `DEPLOY.md` — como ativar o GitHub Pages e ligar `abrazileira.com` / `abrazileira.pt`.

> Este repositório é público. Não colocar aqui material interno do projeto (planos, contactos, plantas, renders, conversas).

Fontes: Cinzel e Cormorant Garamond (SIL Open Font License 1.1), alojadas localmente.
